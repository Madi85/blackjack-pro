# Blackjack Pro – Phase 1

Angular-Web-App mit sechs Decks, S17, Blackjack 3:2, virtuellen Chips, Hit, Stand und einem **vorläufigen** Trainingshinweis. Der Hinweis ist **keine vollständige Basic Strategy**; Pair-Splitting, Double und Insurance werden erst in Phase 2 implementiert.

## Start

Node.js 20.19+ oder eine mit Angular 20 kompatible Node-Version installieren.

```bash
npm install
npm start
```

Danach `http://localhost:4200` öffnen.

## Hinweise

Die Spielmechanik ist ein MVP und noch nicht für Echtgeldbetrieb geeignet. Keine serverseitige Zufallsquelle, kein Echtgeld, keine Konten. Mobile Packaging via Capacitor folgt in Phase 5.
